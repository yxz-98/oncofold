# OncoFold

OncoFold is a web resource for visualizing somatic mutations in 3D protein structures. It enables researchers to interpret mutations in cancer through their structural context, explore significantly mutated regions with ligands and detailed domain annotations, identify spatial clustering indicative of positive selection, and gain mechanistic insights into how specific mutations may alter protein function and contribute to tumorigenesis.

You can find us at [oncofold.org](https://oncofold.org).

For more information about how to use OncoFold, check out the following resources:
